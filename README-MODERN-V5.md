# Nythera Dashboard Modern V5

Diese Version behält die komplette V4-Datenbank- und Rollenlogik und ersetzt nur die Oberfläche durch das moderne erste Design.

Enthalten:
- moderne Management-Übersicht
- Eventverwaltung inklusive Standard-Events aus Supabase
- Member-Ansicht und Rollensteuerung
- Panels im Kartenlayout
- Auszahlungen, Logs, Warnungen, Profile, Setup und Tests
- Next.js Standalone-Build für Railway

Beim Upload den Inhalt dieses Ordners direkt in das Root des Dashboard-Repositories kopieren. Supabase-Daten bleiben erhalten.
